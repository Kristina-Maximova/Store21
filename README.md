# STORE 

___
## *Краткое описание проекта*
Базовое приложение для интернет-магазина.
___
## *Инструкция по установке*

1. Клонируйте репозиторий:

[GitHub](git@github.com:Kristina-Maximova/Store21.git)

2. Установите зависимости:
```
pip install -r requirements.txt
```
3. В корне проекта создайте файл .env по образцу .env.example


4. Выполните миграции:
```
python manage.py migrate
```

5. Наполнение базы данных в приложении catalog тестовыми данными:

```
python manage.py add_products
```

___
## *Примеры использования*

В приложении есть страницы:
- *Главная*, 
- *Категории*, 
- *Контакты*.

Так же можно получить детальную информацию по каждому товару. 

При оформлении страниц использованы стили 
[Bootstrap](https://getbootstrap.com/)


Дополнительно создано приложение для ведения блога


На странице *Контакты* есть форма
обратной связи
для хранения данных используется postgresql
есть возможность администрирования через панель /admin/
